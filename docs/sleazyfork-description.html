✨ The backup button JanitorAI never gave you

One purple ⤓ Backup / Export button on janitorai.com saves your chats, characters, personas and lorebooks, in formats that import cleanly into SillyTavern and the other apps people are moving to.

WhatYou get
💬 ChatsSillyTavern JSONL that actually imports (rerolls become swipes), plus Markdown, TXT, readable HTML and full JSON
🃏 Character cardsPNG with V2 + V3 data and the real avatar, V2/V3 JSON, TXT, raw JanitorAI JSON
📚 LorebooksInside the card, or as a separate SillyTavern World Info file
🎭 PersonasSillyTavern's persona backup format
📦 Back up everythingOne ZIP with all of the above, a manifest, and a skipped.json that says what could not be saved and why

🚀 Quick start

  1. Install Tampermonkey or Violentmonkey.
  2. Click Install this script at the top of this page.
  3. Open janitorai.com, logged in. Click the purple ⤓ Backup / Export button in the corner and pick what to save.

💜 Why this one

  • ✅ Tested for real: live exports from janitorai.com, imported into SillyTavern 1.19.0: card, chat and swipes, every message intact.
  • 🧩 A checklist before every export. Untick any part: system prompt, example dialogs, tags…
  • ✍️ Your text stays your text. Names are kept as written; switching to {{char}}/{{user}} is optional.
  • 🗂️ A small export button on every card in My Characters, favorites and creator pages, plus “export selected” and “export all”.
  • 🛟 Never fails silently. If JanitorAI changes something, the panel says which part broke and links to a prefilled report.
  • 🐢 Polite to JanitorAI: at most 2 requests at once, at least 1 second apart, and it pauses instead of hammering when the site says “slow down”.
  • 📱 Touch-friendly: big buttons, a draggable launcher and a bottom sheet on phones.
  • 🌍 Panel in English, Português (Brasil), Español and Bahasa Indonesia.

🔒 Privacy, plainly

  • Runs entirely in your browser, with your own login.
  • Talks only to janitorai.com and its image server. No analytics, no tracking, nothing sent to us.
  • Hidden definitions are never extracted. If a creator hid a character's definition, you get the public parts (name, picture, tagline, tags, creator, stats) and the export says why. No proxy tricks. Characters you created yourself export in full.

📥 How to import into SillyTavern (click to open)
  1. Character first: Characters → Import Character from File → pick the .png (or .card.json). SillyTavern offers to import the tags.
  2. Then the chat: open that character → Manage chat files → Import chat → pick the .jsonl. (SillyTavern only accepts a chat once the character has been opened.)
  3. Lorebooks come inside the card. Separate .lorebook.json files go in World Info → Import.
  4. Personas: Persona Management → Restore with personas.json. Names and descriptions come back; upload the pictures by hand.
❓ FAQ (click to open)

Why is a character's definition empty?
Either the creator hid it (the panel says so), or you are logged out: JanitorAI only sends definitions to logged-in users, and the panel tells you to log in.

“No chats found on this account”?
Comments on a character page are not chats. Start a chat with “Chat with …”, then back up again.

SpicyChat or Saucepan?
Pick the “SpicyChat / Saucepan” target in the panel. It also fills the card's personality field.

Does it work on phones?
It is built for Firefox for Android with Tampermonkey (bottom sheet, big buttons). It has been tested live on desktop Firefox so far; reports from phones are welcome.

🔐 Permissions, explained (click to open)
  • @connect janitorai.com, ella.janitorai.com: the only sites it may contact (the character data and the avatar images).
  • GM_xmlhttpRequest: to load avatar images so cards carry the real picture.
  • GM_getValue / GM_setValue: to remember your settings.
  • GM_registerMenuCommand: “Back up everything” in the Tampermonkey menu.
  • unsafeWindow: to reuse your existing janitorai.com login, so your chats can be read. It only looks at the login header of the site's own requests, never at their content, and never changes them.
